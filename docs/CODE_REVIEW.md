## Найденные и исправленные проблемы

| Приоритет | Проблема до рефакторинга | Исправление |

| P1 | Перед оплатой сравнивались только сумма и количество; другой товар с той же ценой мог пройти проверку | Сравнивается снимок состава, валюты, адреса и доставки |
| P2 | GoRouter пересоздавался при изменении авторизации и терял текущий маршрут | Стабильный роутер, refreshListenable и возврат к запрошенному экрану |
| P2 | При временной ошибке восстановления сессии сохранённый токен удалялся | Сетевая ошибка сохраняет токен для следующей попытки |
| P2 | shared читал настройки из entities; сущности импортировали соседние сущности | Параметры shared внедряются в app; данные разделены на слайсы catalog/customer/order/auth/settings |

| P2 | HTTP-клиенты каталога и OTP не закрывались | Единый транспорт закрывает принадлежащие ему клиенты в finally; внедрённым клиентом владеет вызывающий код |
| P2 | PhoneAuthPage и обе OTP-формы одновременно слушали ошибки авторизации | Один слушатель на странице |
| P2 | Новый интерфейс содержал переводы в Dart вместо существующего l10n | Строки перенесены в ARB, используются сгенерированные AppLocalizations |
| P2 | При прямом открытии экрана стандартный AppBar мог скрывать кнопку назад | Явный AppBackButton с родительским маршрутом |
| P2 | Асинхронное сохранение профиля могло обновить UI после ухода со страницы или смены пользователя | Проверки mounted и актуальности репозитория |
| P2 | Контроллер оформления и изменение корзины могли обращаться к уничтоженному UI | Защита жизненного цикла контроллера и поколения состояния |

## Структурные изменения

Репозитории, провайдеры и UI разделены на api/model/ui/lib с публичными index.dart.
Cart и история заказов принадлежат одной сущности order. Checkout — feature.
Страницы собирают готовые блоки и передают переходы между маршрутами.

Вынесены ProductCard, OrderTotals, PriceText, PaginationBar, AppNetworkImage,
AsyncContent/RetryView и AppBackButton. Checkout разделён на контроллер и шаги;
редактирование профиля и добавление в корзину выделены в features.

Тесты больше не импортируют другие тестовые наборы: общие заглушки находятся
в test/support. Добавлены регрессионные проверки маршрутизации, жизненного цикла,
транспорта, состава заказа перед оплатой, границ FSD, локализации и кнопки назад.

## Практические ограничения

В текущем API сохранён Json вместо новых генерируемых DTO. Тестовая оплата
по-прежнему использует существующий dummyPaymentHandler; интеграция реального
платёжного провайдера этим изменением не добавлялась. Старый email-сценарий
сохранён через SDK-адаптер; основные Shop API-запросы и OTP используют ShopApi.
