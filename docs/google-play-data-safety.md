# LOLO — черновик Data safety и App content

Этот документ — рабочая карта для Play Console. Перед отправкой её нужно сверить
с реальной production-инфраструктурой, договорами с Telegram/WhatsApp,
платёжным провайдером, аналитикой и серверными логами.

## Data collection and security

- Приложение собирает данные пользователей: **Да**.
- Данные шифруются при передаче: **Да**, production API использует HTTPS.
- Пользователь может запросить удаление данных: **Да**.
- In-app путь: `Настройки → Удалить аккаунт`.
- Внешний URL: `https://lolo.tj/account/delete`.

## Категории данных

| Категория Play Console | Данные LOLO | Назначение |
| --- | --- | --- |
| Personal info | Имя, фамилия, телефон, необязательный email | Account management, app functionality |
| Personal info | Адрес доставки | App functionality, order fulfillment |
| Financial info | История покупок и суммы заказов | App functionality, order management |
| App activity | Корзина и взаимодействие с товарами | App functionality |
| Device or other IDs | Токен сессии в защищённом хранилище | Account management, security |

IP-адрес и технические HTTP-логи нужно декларировать в соответствии с их
фактическим хранением и использованием на production-сервере.

## Sharing — требуется финальная проверка

- Telegram и WhatsApp участвуют в доставке одноразового кода.
- Если поставщики действуют как service providers по поручению LOLO, проверьте
  исключение Google Play для передачи поставщику услуг.
- Если данные используются поставщиком для собственных целей, соответствующие
  категории нужно отметить как shared.
- При подключении платежей или аналитики пересмотрите декларацию до релиза.

## Остальные разделы App content

- Ads: **Нет**, пока рекламный SDK и реклама отсутствуют.
- App access: предоставить Google тестовый номер/аккаунт и точную инструкцию OTP.
- Content rating: заполнить анкету как marketplace/shopping app.
- Target audience: выбрать фактическую возрастную аудиторию; не заявлять детей,
  если приложение и политика не подготовлены для Families Policy.
- News app: **Нет**.
- Government app: **Нет**.
- Financial features: перепроверить после подключения реального платежного
  провайдера; обычная продажа физических товаров сама по себе не делает LOLO
  финансовым приложением.

## Блокеры перед отправкой

- внешний URL удаления аккаунта должен отвечать `200` без авторизации;
- OTP Telegram/WhatsApp должен работать в production;
- должны быть настроены реальные доставка, валюта и оплата;
- политика конфиденциальности должна описывать все перечисленные данные,
  поставщиков, сроки хранения и процедуру удаления;
- финальная AAB должна быть подписана постоянным upload key, не debug-ключом.
